# Shared brief — NutriDay (FoodTech MVP)

## Product
**NutriDay** — веб/мобильный MVP заказа готовых наборов здорового питания на день/неделю с оплатой и доставкой.

## Audience
25–45 лет, ограниченный бюджет, хотят экономить время на готовке без сложной кастомизации меню.

## MVP features (Must have)
1. Выбор типа питания / рациона и просмотр меню наборов
2. Корзина: добавление набора, изменение количества, итог
3. Оформление заказа: дата доставки (≥+2 дня), адрес, оплата

Out of MVP: сложная кастомизация блюд, своя логистика, AI-рекомендации.

## Stack (for ДЗ2 context / later ДЗ4)
Next.js (App Router) + TypeScript + Tailwind CSS. AI-агент разработки: Cursor.
