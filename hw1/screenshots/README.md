# Скриншоты для ДЗ1 (Cursor)

Каталог предназначен для иллюстраций к **Шагу 4** и **Шагу 5** отчёта `../report.md`.  
На момент подготовки текста файлы изображений могут отсутствовать — ниже список того, что нужно добавить позже.

## Что сделать

1. Сделать скриншоты в Cursor по списку ниже.  
2. Сохранить файлы **в эту папку** (`hw1/screenshots/`).  
3. Использовать понятные имена (латиница, без пробелов).  
4. **Не** снимать и **не** прикладывать экраны с секретами: `.env`, API-ключи, реальные адреса/карты, личные токены.

Рекомендуемые форматы: `.png` или `.jpg`.
