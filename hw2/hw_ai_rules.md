# ДЗ2. Шаг 1 — Требования к проекту и правилам для AI-агента

## Проект

**NutriDay** — веб/мобильный MVP сервиса заказа готовых наборов здорового питания на день или неделю с оплатой и доставкой.

**Аудитория:** 25–45 лет, ограниченный бюджет, хотят экономить время на готовке без сложной кастомизации меню.

**MVP (Must have):**
1. Выбор типа питания / рациона и просмотр меню наборов
2. Корзина: добавление набора, изменение количества, итог
3. Оформление заказа: дата доставки (≥+2 дня от сегодня), адрес, оплата

**Вне MVP:** сложная кастомизация блюд, своя логистика, AI-рекомендации.

## Стек

| Слой | Технология |
|------|------------|
| Фреймворк | Next.js (App Router) |
| Язык | TypeScript (strict) |
| Стили | Tailwind CSS |
| AI-агент разработки | **Cursor** |

## Требования к стилю кода

1. **TypeScript strict:** запрещён `any`; явные типы для props, API-ответов и доменных сущностей.
2. **Именование:** компоненты и типы — `PascalCase`; функции/хуки/переменные — `camelCase`; константы окружения — `UPPER_SNAKE`.
3. **Компоненты:** функциональные React-компоненты; серверные по умолчанию в App Router; `'use client'` только при необходимости (состояние, браузерные API).
4. **Стили:** только Tailwind utility-классы; без инлайн-стилей и CSS-модулей без веской причины.
5. **Импорты:** абсолютные алиасы `@/` для `src`/`app`; без глубоких относительных цепочек `../../../`.
6. **Ошибки:** явная обработка ошибок (тип `Result` / `try-catch` / UI-состояния), без «пустых» `catch`.

## Требования к архитектуре

1. **App Router:** маршруты в `app/`; UI-компоненты в `components/`; доменная логика в `lib/` (корзина, даты доставки, валидация заказа).
2. **Разделение слоёв:** UI не содержит бизнес-правил доставки/оплаты; правила — в чистых функциях `lib/`.
3. **Состояние корзины:** единый источник правды (context/store); пересчёт суммы в одной функции.
4. **Дата доставки:** минимально `сегодня + 2 дня`; валидация на клиенте и на сервере (Server Action / API).
5. **Типы домена:** `MealPlan`, `CartItem`, `Order`, `DeliveryAddress` в `types/` или `lib/types.ts`.
6. **Безопасность:** секреты только в env; не логировать платёжные данные.

## Цель правил для Cursor

Правила должны зафиксировать роль агента, контекст NutriDay, стиль кода, жёсткие запреты и формат ответа — чтобы генерация была предсказуемой и согласованной со стеком.
