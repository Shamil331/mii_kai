# NutriDay — описание проекта (ДЗ3)

## Проблема

Работающие люди 25–45 лет хотят питаться сбалансированно, но не готовы тратить вечера на планирование меню, закупку продуктов и готовку. Сервисы с глубокой кастомизацией блюд перегружают выбором и часто выходят за скромный бюджет. Классическая доставка еды даёт разовые заказы без понятного рациона на день или неделю.

NutriDay закрывает разрыв: готовые наборы здорового питания с фиксированным составом, прозрачной ценой и простой доставкой — без конструктора блюд и без «умных» рекомендаций.

## Ценностное предложение

**NutriDay** — адаптивное веб-приложение (web + mobile-friendly) для заказа готовых наборов здорового питания на день или неделю с оплатой и доставкой.

Пользователь за несколько минут:

1. выбирает тип рациона и смотрит меню набора;
2. кладёт набор в корзину и корректирует количество;
3. указывает дату доставки (не раньше чем через 2 дня), адрес и оплачивает заказ.

Ценность для клиента: экономия времени, предсказуемый бюджет, понятный состав рациона без сложной настройки.

## Целевая аудитория

| Параметр | Описание |
|----------|----------|
| Возраст | 25–45 лет |
| Контекст | Работа / учёба, мало времени на готовку |
| Бюджет | Ограниченный; важна прозрачная цена набора |
| Ожидания | Готовые наборы, ясное меню, быстрый чекаут |
| Устройства | Смартфон и десктоп; приоритет — удобство на узком экране |

**Персоны (кратко):**

- **Анна, 32** — офис-менеджер, хочет «есть нормально» в будни без готовки каждый день.
- **Игорь, 28** — фрилансер, считает расходы; сравнивает цену дня/недели до оплаты.
- **Марина, 41** — совмещает работу и семью; нужна доставка к конкретной дате и адресу.

## MVP: ключевые функции (≥3)

### 1. Выбор типа питания и просмотр меню наборов
Пользователь видит доступные типы рационов (например, сбалансированный / лёгкий / белковый — без глубокой персонализации) и открывает карточку набора: состав на день или неделю, калорийность (если указана), цена, фото/описание блюд.

### 2. Корзина
Добавление набора, изменение количества кнопками «+» / «−», автоматический пересчёт суммы, удаление позиции при количестве 0, отображение итога заказа.

### 3. Оформление заказа: дата, адрес, оплата
Выбор даты доставки с учётом минимального срока производства (**не ранее чем через 2 календарных дня**), ввод адреса доставки, подтверждение и оплата. После успешной оплаты — экран подтверждения с номером заказа и ключевыми деталями.

## Что не входит в MVP

- Сложная кастомизация отдельных блюд и ингредиентов  
- Собственная курьерская логистика и трекинг в реальном времени  
- AI-рекомендации рационов  
- Подписки с автопродлением, бонусные программы, реферальная система  

## Формат продукта

| Параметр | Решение |
|----------|---------|
| Тип | Responsive web app (удобно на мобильном и десктопе) |
| Стек (ориентир) | Next.js (App Router), TypeScript, Tailwind CSS |
| Срок MVP | ~3 месяца (учебный контекст) |
| Рынок | FoodTech, готовое здоровое питание |

## Критерии успеха MVP (измеримые ориентиры)

- Пользователь может пройти путь «меню → корзина → оплата» без обращения в поддержку.  
- Дата доставки раньше «сегодня + 2 дня» недоступна для выбора.  
- Итоговая сумма в корзине и на чекауте совпадает с суммой позиций.  
- После оплаты отображается подтверждение с идентификатором заказа.

## Краткое резюме

NutriDay — минимальный, но полный цикл заказа готовых наборов здорового питания: выбор рациона, корзина, доставка и оплата. Фокус на скорости и ясности для аудитории с ограниченным временем и бюджетом; расширение функций — за рамками MVP.
